# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, and assume good intent. Harassment or abuse of any kind is not tolerated.

Report unacceptable behavior to the maintainer by contacting them through their [GitHub profile](https://github.com/abideenz01). All reports are reviewed and handled in confidence.
