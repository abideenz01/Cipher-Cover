# Cipher Cover: notes for coding agents

Before you plan or change anything, read these in full:

1. `docs/SPEC.md`: what the business needs
2. `docs/ARCHITECTURE.md`: how the parts fit together
3. `docs/TECH_STACK.md`: the tech choices
4. `docs/CODE_STANDARDS.md`: how to write the code
5. `docs/PROCESS.md`: how to plan, build and check the work
6. `docs/BRAND.md`: the look
7. `docs/STATUS.md`: what's built and how to run it

Rules:

- `npm run check` must pass before every commit.
- Update `docs/STATUS.md` after every change.
- Never commit `.env` or any secret.
