# Tech stack

- `backend/`: FastAPI on SQLAlchemy Core: SQLite for tests and local work, PostgreSQL on Supabase (session pooler, schema `undercover`, row-level security, at most 4 connections a process) when `DATABASE_URL` is set. Every API operation has an `operation_id`, a one-line docstring and no optional inputs. Paying a claim is a separate operation that takes the amount.
- `agent/`: agents on OpenRouter, with entry points that take ids. The queue agent, `run_queue(queue_run_id)` in `agent/queue.py`, is LangChain's `create_agent`; it plans the run as a to-do list and hands each claim to a fresh claim agent. The claim agent, `run(claim_id, thread_id)` in `agent/main.py`, is a LangGraph `StateGraph` (`agent/graph.py`: think, act, settle) that works one claim. The thread id is the claim run's id. Its progress is saved after every step by `PostgresSaver` in the `undercover` schema (an in-memory saver without `DATABASE_URL`), and it waits for sign-off with `interrupt()`. The graph's nodes do what middleware did: provider errors are retried three times, a claim has at most 30 model calls, and every step is recorded on the claim. Both agents reach claims, the wording and the manual (one section at a time) and their instructions only through the backend's API. `agent/service.py` is the agent's service (`UNDERCOVER_AGENT`, default `http://127.0.0.1:8002`, `AGENT_SERVICE_KEY` both ways): the backend wakes it after a sign-off or a restart, and it carries on every claim that is due. Traces go to Langfuse when its keys are set, one session per claim run. They use `deepseek/deepseek-v4.1-flash` with low reasoning effort by default, or the model in the environment variable `MODEL_NAME` if set, such as `openrouter/free`.
- `dashboard/`: React, Vite and TypeScript.
- `e2e/`: Playwright tests.
- `data/`: the business data the backend starts from. The agent never sees `data/evals/`, which holds the answer key.

Python 3.12 with uv, all in the root `pyproject.toml`. Node 26. The OpenRouter key is `OPENROUTER_API_KEY` in `.env`.
